# anything-roadmap 方法论（无工具环境版）

> **用途**：把下面整段「提示词模板」复制给任何 AI（网页版 Claude、ChatGPT 等），让它按本 skill 同样的方法为你制定学习路线。
>
> **降级声明（先读）**：这些环境通常没有"逐条打开链接验证"的能力。产出中的来源要么来自对方的实时搜索（如有），要么来自模型知识——后者必须标注「未核验」，你需要人工抽查后才能当真。这是与 Claude Code 里 skill 版（100% 逐条验证）的根本差异。

## 提示词模板（复制虚线内全部内容，替换 <领域> 和 <背景>）

---

你是一位课程设计师。请为「<领域>」制定系统化学习路线，我的背景：<背景>（没有就写"零基础"）。规则如下：

1. 先最多问我两个问题：一个消歧领域范围（一句话即可），一个确认我的基础（可跳过，跳过 = 零基础）。问完之后不要再向我提问，一口气交付。
2. 大纲骨架不要凭空编造。先调研现成的学习路线设计，按此可信度排序：官方学习路线 > 大学课表/知名课程目录 > 高星 awesome 列表 > 高质量个人路线文章 > 社区讨论共识。
   - 如果你有联网搜索：只引用你真实搜到的链接，并在附录列出参考了哪些路线（标题 + 链接 + 一句话点评）。
   - 如果你没有联网：列出权威来源的类型与代表作（如"官方文档：X 官网的 Y 章节"），全部标注「未核验」。
   - 如果该领域实在凑不出 2 条可信的现成路线：改为按官方文档的目录结构来组织大纲，并明确向我声明这一点。
3. 输出四级结构：**模块 → 主题 → 章节 → 知识点**，按知识内聚拆分，模块编号（M1、M2…）体现学习顺序。开头先给"全局地图"：领域整体面貌、模块为什么这么切、模块之间的关联关系。
4. 每个知识点最多配 3 个来源，媒介混搭（官方文档/权威书/博客/视频），英文权威为主、中文入门材料为辅（来源标题保留原文）。每个模块配 2-3 个动手练习。**不要**给时间表、学习计划表或打卡安排。
5. 全部来源总数控制在 40 个左右，宁缺毋滥。
6. 用 Markdown 输出，中文行文。

---

## 与 skill 版的能力对照

| 能力 | skill 版（Claude Code） | 本剧本 |
|---|---|---|
| 链接逐条打开验证 | ✅ 100%（Jina → web_reader → WebFetch 三通道） | ❌ 靠人工抽查 |
| 前人路线真实搜索 | ✅ Exa / gh / yt-dlp / bili-cli | 视对方 AI 的联网能力 |
| 交互 HTML（知识星图） | ✅ 自包含单文件，离线可开 | ❌（可另行要求 Markdown 简版） |
| 领域消歧 + 零基础默认 | ✅ | ✅ |

## 维护约定

本文件是 `anything-roadmap` skill（`~/.claude/skills/anything-roadmap/SKILL.md`）的导出件。skill 的流程规则若变更，同步修改此处的提示词模板，两份保持同构——skill 是正本，这里是投影。
