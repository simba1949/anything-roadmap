# 教学会话协议

## 1. 定向

用不超过一屏的信息说明：

- 完整领域中的模块位置；
- 个人路径中的当前能力及其前后依赖；
- 这项能力对毕业任务的贡献；
- 已有证据、到期复习和建议目标。

定向是教学动作，不是装饰性报幕。进入新模块和结束会话时都要把局部放回全局。

## 2. 选择入口

默认建议“尝试优先”，但明确允许学习者选择“讲授优先”。

### 尝试优先

首次任务要小、低风险、有分叉价值。它用于识别当前心智模型，不用于制造挫败。不同答案必须真实改变后续教学，否则不要问。

### 讲授优先

先给完整但聚焦的心智模型、正例和边界，再进入主动回忆与变式。讲授后不更新掌握等级，直到获得独立表现证据。

## 3. 教学策略

| 策略 | 主要动作 | 合适证据 |
|---|---|---|
| memory | 提取线索、间隔回忆、辨析 | 无提示回忆与识别 |
| mental_model | 因果解释、正反例、预测 | teach-back、预测新案例 |
| procedure | 示范、分步练习、撤除脚手架 | 可运行或可观察结果 |
| quantitative | 建模、推导、单位与边界检查 | 步骤与结果双重检查 |
| judgment | 对比情境、约束权衡、反方挑战 | 量规与辩护 |
| design | 范例分析、约束创作、迭代批评 | 量规、作品和反思 |

## 4. 反馈和补救

反馈必须说明判定依据和置信度。顺序：做对之处、错误机制、最小修正、新的短尝试。不要一次给出所有可用提示。

补救升级：

1. 修正当前错误机制；
2. 更换表示、案例或解释角度；
3. 检查前置能力；
4. 插入补救能力；
5. 目标或约束失配时，与学习者协商重规划。

`ambiguous_task` 或 `unreliable_grading` 属于课程/评价问题，不能记录为学习者失败。

## 5. 前进与复习

达到能力契约中的最低等级后可以暂时前进。`far_transfer` 主要通过跨能力综合任务获得；`retained` 必须来自跨会话、延迟后的新任务。

复习任务不能只要求重读或重做原题。先主动回忆，再改变情境；失败时回到最小必要内容。

## 6. 收尾

会话结束报告：

1. 本次产生的证据及强度；
2. 尚未闭合的错误或不确定项；
3. 当前地图位置；
4. 下一复习时间；
5. 2-3 个下一步选择及其影响。
