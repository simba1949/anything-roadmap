- [ ] capability ID 唯一

## 来源与渲染

- 候选 / 已读 / 入选 / 剔除：
- [ ] 正式 URL 已实际打开
- [ ] self-study 可独立理解
- [ ] roadmap.html 同时显示全局和个人路径
- [ ] HTML 单文件、零 CDN、窄屏/键盘/打印/reduced-motion 可用
- [ ] 产品型地图已对照官方 README、文档导航、CLI/API 入口或版本说明
- [ ] 影响工作流、权限或结果投递的正式功能没有被泛化模块吞没
- [ ] 学习者已掌握功能保留为基线，但未占用主要教学时间
- [ ] 用户可见过程说明未暴露底层联网工具路由

## 研究时效与路线处理

- [ ] 稳定知识结构与最新状态分别经过深度研究，而非一次功能扫描
- [ ] 地图的 as_of 对该领域的变化速度仍然有效
- [ ] 当前稳定变化已按毕业任务进入 core/support/branch/deferred
- [ ] 实验性内容标明风险，未被当作默认必学路径
- [ ] 已废弃或移除内容只用于迁移/兼容，不作为当前默认
- [ ] 计划中或未证实内容没有被写成当前可用能力
