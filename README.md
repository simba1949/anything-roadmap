# anything-roadmap

[English](./README.en.md) | 中文

> **一句话介绍**：为任意领域自动生成系统化学习路线的 AI skill —— 真实调研前人路线设计、逐条验证权威源、产出可交互知识星图。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)
[![Skill Type](https://img.shields.io/badge/Type-Learning%20Path%20Generator-green.svg)]()

**核心能力**：先真实调研**前人的学习路线设计**作骨架（官方路线/大学课表/awesome 列表/社区共识），再为每个知识点搜索并**逐条打开验证**权威源（官方文档/博客/视频/网站），产出 Markdown + 自包含交互 HTML（知识星图）双格式。

---

## 快速开始

### 安装

**方式一：自动安装（推荐）**
```bash
npx skills add simba1949/anything-roadmap
```

**方式二：手动安装**
1. 克隆或下载本仓库
2. 将 `SKILL.md` 和 `references/` 目录复制到你的 skill 目录
   - Claude Code: `~/.claude/skills/anything-roadmap/`
   - 其他环境: 参考对应 AI 工具的 skill 安装路径
3. 重启或重新加载 skill

**验证安装**：在 AI 对话中输入 `/skills` 或 `/skills list`，应该能看到 `anything-roadmap`。

### 基础使用

```bash
# 基础调用（默认零基础）
/anything-roadmap Rust编程

# 带背景信息
/anything-roadmap 分布式系统 有5年后端开发经验

# 交叉学科
/anything-roadmap 量子计算 物理学本科背景
```

**产出物**：在当前目录生成 `./<领域>-roadmap-<日期>/` 文件夹
- `syllabus.md` — 完整学习路线（Markdown）
- `index.html` — 可交互知识星图（单文件，零依赖，离线可开）

### 使用示例

#### 示例 1：零基础学习新技术
```bash
/anything-roadmap Kubernetes
```
**适用场景**：想系统学习 K8s，不知道从哪里开始

**生成内容**：
- 从容器基础到 K8s 核心概念的渐进式路线
- 官方文档 + 互动教程 + 中文入门视频混搭
- 每个模块配动手实验（如搭建本地集群）

#### 示例 2：有经验的进阶学习
```bash
/anything-roadmap 分布式系统 有3年Java微服务开发经验，用过Redis和Kafka
```
**适用场景**：有实践经验，想深入理解原理

**生成内容**：
- 跳过基础，聚焦一致性协议、复制策略、容错机制
- 论文 + 深度博客 + 源码解析
- 练习偏向设计与实现（如手写 Raft）

#### 示例 3：冷门/小众领域
```bash
/anything-roadmap WebAssembly编译器开发
```
**适用场景**：搜不到现成学习路线的新兴领域

**生成内容**：
- 自动降级为"官方文档结构为骨"模式
- 以 Wasm 规范文档目录组织大纲
- 补充编译原理前置知识
- 明确声明"该领域未找到足够前人路线"

## 核心特性

### 🎯 真实调研，拒绝凭空编造
- **前人路线为骨**：搜索官方学习路线、大学课表、awesome 列表、高质量个人路线
- **可信度阶梯**：官方 > 课表 > 社区共识，按权威性排序
- **降级模式**：搜不到 ≥2 条可信路线时，自动切换为"官方文档结构为骨"并显式声明

### ✅ 逐条验证，零幻觉链接
- **三通道接力**：Jina Reader → web_reader → WebFetch，确保每个链接真实可访问
- **三问准入**：活着？对题？权威？全部通过才放行
- **验证统计**：结尾附"搜到 X / 通过 Y / 剔除 Z"明细

### 📚 四级大纲，知识内聚
- **模块 → 主题 → 章节 → 知识点** 四级结构
- 模块编号（M1/M2/M3...）体现学习顺序
- 每模块含设计理由、参考路线、动手练习

### 🌐 媒介混搭，中英互补
- **英文权威为骨**：官方文档、经典书籍、深度博客
- **中文教学为辅**：B站视频、知乎/掘金入门文、尚硅谷课程
- 媒介多样：DOC（文档）/ BLOG（博客）/ VID（视频）/ SITE（网站）

### 🗺️ 可交互知识星图
- **单文件 HTML**：零 CDN 依赖，完全离线可开
- **暗色 HUD 设计**：领地地图隐喻，模块=领地、关系=路线
- **可交互下钻**：四级折叠、媒介筛选、模块跳转、悬停高亮
- **一键复制链接**：点击来源卡片自动复制 URL

### 🔄 一站到底，纠错重跑
- **零中断**：消歧之后不再提问，一次性生成完整产物
- **纠错=重跑**：不修补旧稿，带纠正意见全新生成（新日期目录）
- **一次性快照**：不做增量刷新，源老化时整份重跑

## 适用场景

### ✅ 推荐使用
- **零基础入门**：想系统学习某个新技术/领域，不知从何开始
- **进阶深化**：有基础经验，想建立完整知识体系
- **技术选型调研**：快速了解某个技术栈的学习成本和资源情况
- **团队培训规划**：为团队制定统一的学习路线
- **交叉学科**：需要融合多个领域的知识（如 AI + 金融）
- **冷门/新兴技术**：搜不到现成教程的小众方向

### ⚠️ 不适合的场景
- **已有完整课程资源**：如果你已经报名了某个系统课程，直接跟课即可
- **需要实时更新**：本 skill 生成一次性快照，不追踪技术更新
- **需要个性化答疑**：这是路线规划工具，不能替代导师/社群的答疑
- **考试/认证备考**：考试大纲通常有官方指定材料，优先使用官方资源

## 无工具环境替代方案

如果你使用的 AI 工具不支持 skill 调用（如网页版 Claude、ChatGPT），可以使用导出的方法论：

📄 **[references/playbook.md](./references/playbook.md)** — 完整提示词模板

**使用方法**：
1. 打开 `references/playbook.md`
2. 复制"提示词模板"部分的全部内容
3. 替换 `<领域>` 和 `<背景>` 为你的实际需求
4. 粘贴给任何 AI（ChatGPT/Claude/Gemini/Perplexity）

**⚠️ 注意**：无工具环境无法做到 100% 逐条验证链接，生成后需要**人工抽查至少 20% 的链接**。详见 playbook.md 中的验证清单。

## 依赖说明

无硬依赖。搜索层优先复用环境里已安装的搜索类 skill（如 agent-reach），缺席时自动降级到内置 WebSearch/WebFetch；链接验证三通道接力（Jina Reader → web_reader → WebFetch），任一可用即可。
