# validation.md 模板

```markdown
# <领域>知识地图验证报告

> 地图：<domain_map_id>@<version> | 验证日期：<date>

## 结论

- 状态：通过 | 带警告通过 | 未通过
- 阻断问题：
- 重要警告：

## 证据与来源

- 检索截止（as_of）：
- 最新信息窗口及理由：
- 当前稳定版本/现行规范：
- 候选来源：
- 全文阅读：
- 入图来源：
- 剔除：
- 未能核验：

## 结构验证

- [ ] ID 唯一
- [ ] 层级合法
- [ ] 主题/章节没有单子节点空壳
- [ ] 所有关系端点存在
- [ ] 所有来源引用存在
- [ ] 典型遍历只引用存在节点

## 覆盖验证

- [ ] 基础
- [ ] 核心
- [ ] 主要分支
- [ ] 典型应用
- [ ] 相邻接口
- [ ] 当前前沿
- [ ] 包含与排除边界
- [ ] 软件/平台/工具领域已对照官方功能面
- [ ] 可配置、可调用、可观察或可排障的正式入口均为可见节点
- [ ] 影响日常工作流、权限或结果投递的功能没有被泛化模块吞没

## 双轨时效验证

- [ ] 稳定知识结构轨经过多轮深度研究
- [ ] 最新状态与变化轨经过独立的多轮深度研究
- [ ] 当前基线由现行官方资料核验，不是从“最新”搜索结果猜测
- [ ] 近期变化记录发布/发生日期、生效日期和适用版本
- [ ] 稳定、新增、实验性、已废弃、已移除、计划中已明确区分
- [ ] 已废弃/移除内容未作为默认遍历入口
- [ ] 未证实的最新说法只进入缺口，没有写成正式事实

## 渲染验证

- [ ] Markdown 与 JSON 计数一致
- [ ] HTML 与 JSON 计数一致
- [ ] HTML 单文件且零 CDN
- [ ] 键盘导航、窄屏、打印、reduced-motion 可用
- [ ] 空数据和长名称不会破坏页面

## 低置信结构与信息缺口

| 位置 | 问题 | 影响 | 后续动作 |
|---|---|---|---|
```
